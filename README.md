# nagasudhamani-git
A Git and GitHub practice repository demonstrating version control, meaningful commits, and repository documentation.
This repository is created to demonstrate my understanding of Git and GitHub through practical version control activities, including repository creation, meaningful commits, documentation, and maintaining a clear project history. It serves as a simple record of my progress in using Git for managing and tracking changes in a project.

## Useful Git Commands

- `git status` - Check the current repository status
- `git add` - Stage changes
- `git commit` - Save changes to the repository history
- `git push` - Upload local changes to GitHub
- `git pull` - Get the latest changes from GitHub
